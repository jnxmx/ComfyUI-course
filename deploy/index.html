Открыть API Keys
Как получить ключ
  1. Нажмите «Открыть API Keys» сверху и выберите Create API Key.
  2. В списке REST API поставьте обе галочки у All resources (Read и Write).
  3. Сверните REST API, откройте GraphQL и выберите Read, Write (достаточно Read only).
  4. Нажмите Create, скопируйте ключ и вставьте его в поле API Key выше.

Требования к API-ключу RunPod
  • REST API: Pods (Read + Write), Templates (Read), Secrets (Read), Catalog (Read).
  • GraphQL API: Read only (для потоковых логов подов).
  • Или создайте ключ со всеми правами (All permissions).

Безопасное хранение ключа

  • Сайт работает полностью в вашем браузере без собственного бэкенда и промежуточных серверов — ключ хранится только локально в localStorage вашего устройства.
  • Все запросы уходят напрямую с вашего компьютера на официальный https://api.runpod.io/v2 по защищённому HTTPS (это можно проверить во вкладке Network в DevTools).
  • Исходный код открыт на GitHub; удалить ключ можно в один клик кнопкой «Забыть» или отозвать его в любой момент в настройках аккаунта RunPod.
