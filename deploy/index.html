Этот текст, так же как и весь интерфейс, сделан с помощью генеративного ИИ — так что это не может быть полностью безопасно, но:

  • Ключ никуда не отправляется: страница работает полностью в вашем браузере без собственного бэкенда и промежуточных серверов. API-ключ хранится только локально в localStorage вашего устройства.
  • Прямое соединение с RunPod: все запросы с ключом уходят напрямую с вашего компьютера на официальный https://api.runpod.io/v2 по защищённому HTTPS-соединению.
  • Открытый исходный код: код сайта открыт на GitHub, а во вкладке Network в DevTools можно в любой момент проверить, что ключ передаётся только в RunPod API.
  • Полный контроль: вы можете в один клик удалить ключ кнопкой «Забыть ключ» или отозвать его в любой момент в настройках аккаунта RunPod.
Требования к API-ключу RunPod
  • Минимум в REST API: Pods (Read + Write), Templates (Read), Secrets (Read), Catalog (Read).
  • Минимум в GraphQL API: Read only (обязательно для чтения потоковых логов подов).
  • Либо просто создайте ключ со всеми правами (отметить все галочки).
